# Akmon — site e documentação privada

Repositório privado do site, estudos de identidade e documentação do Akmon.
A biblioteca pública de skills permanece em https://github.com/RafaelMKn/skills-library.

## Conteúdo

- `design_system/identidades/`: estudos e páginas HTML estáticas.
- `docs/`: identidade, ilustração e experimentos ASCII.
- `PRODUCT.md`: contexto de produto original.
- `.impeccable/review/`: evidências e prévias de revisão preservadas na migração.

## Executar localmente

Na raiz deste repositório:

    python3 -m http.server 8000 --bind 127.0.0.1

Abra http://127.0.0.1:8000/design_system/identidades/.

## Privacidade

Não habilitar GitHub Pages nem deployment público sem decisão explícita.
Um repositório privado não torna um deployment privado: hospedagem futura precisa de controle de acesso próprio.

A migração preservou os arquivos de trabalho, incluindo alterações ainda não commitadas, sem importar o histórico do repositório público. Referências históricas em PRODUCT.md refletem o contexto anterior à separação.
